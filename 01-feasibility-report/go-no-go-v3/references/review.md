# רובריקה לבודק

הבודק מקבל את `review_pack.sh` (עמודים כתמונות, `data.json`, הקובץ הזה) ולא ראה את העבודה. ציון 1–10 לכל ציר:

| ציר | מה נדרש לציון 8 ומעלה |
|---|---|
| בהירות ההכרעה | GO / גבולי / NO-GO עם מספר; בגבולי וב-NO-GO — מה הופך ל-GO, בכמות |
| עקיבות | כל מספר מתויג; 10 מספרים אקראיים נעקבים עד המקור ב-`data.json` |
| הגיון הארכיטיפ | מדד הכותרת נגזר מהארכיטיפ; במקרה גבול מוצגים שני המדדים |
| סבירות כלכלית | נקודת איזון מול חציון העסקאות, גריד 3×3, שווי שיורי מתחת ל-40% מההכנסות, בשלב 3: מעטפת מול כל חלופה |
| נכונות תכנונית | הפרדה בין מאושר, בהליך ושכבה; ארבעת המקורות נבדקו, כולל "חסר" · בשלב 3: כל חלופה לפי israel-massing-rules, אילוץ חוסם נכון |
| עימוד ו-RTL | אין שבירות bidi, אין כותרות יתומות, המפות קריאות |
| כנות | מה שחסר מוצג כחסר; מד הוודאות אומר את האמת |

**פלט הבודק:** ציון לכל ציר, ממוצע, ושלוש הבעיות החמורות עם עמוד וסעיף.
**סבבים:** לכל היותר שניים. אחרי שני סבבים מתחת ל-8 בממוצע — מוסרים עם הבעיות הפתוחות, בגלוי.
**בלי סוכן שני** (claude.ai): הסקיל ממלא את הרובריקה וכותב במפורש "הציון ניתן על ידי הסקיל עצמו".
