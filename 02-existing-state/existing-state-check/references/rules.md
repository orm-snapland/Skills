# כללי אצבע ומלכודות — מצב קיים

## כללי אצבע (מקור: טל דיין, שמאי ויזם, שיחה 01.10.2026)
| נושא | כלל |
|---|---|
| חדר מדרגות בבניין קיים | ~15 מ"ר לקומה לכל כניסה |
| שטח דירה קיימת | טביעת רגל × קומות למגורים, פחות הגרעין, חלקי יח"ד |
| נסח טאבו | נמוך ב-15–20% מהמציאות |
| תמורה לבעלים | תלויה בעיקר בשטח הנטו הכולל, פחות במספר הדירות |
| גובה קומה | 2.6–3.5 מ'. מחוץ לטווח = קומת עמודים או מבנה גג |

כל ערך כאן הוא ברירת מחדל מתויגת `כלל אצבע`. ערך ממסמך, ממדידה או מהמזמין גובר תמיד, ואז התג `מסמך` או `החלטה`.

## רמות דיוק
●○○○ נסח טאבו (מוטה נמוך 15–20%) · ●●○○ פוליגון GIS + כלל אצבע · ●●●○ מדידה גרפית מהיתר או מתשריט · ●●●● מודד.
הסקיל הזה מגיע ל-●●○○ לבד, ול-●●●○ כשמוזנת מדידה מ-`permit-measurement`.

## מלכודות
| מלכודת | בדיקה |
|---|---|
| פוליגון כולל מרפסות | פוליגון המבנה ב-GIS נגזר מקו הגג או מתצ"א; הברוטו הסגור נמוך ב-3–6%. נרשם כדגל, לא מתוקן בשקט |
| קומת עמודים | `has_pillar_floor` או גובה ÷ קומות מתחת ל-2.6 — הקומה יורדת מהקומות למגורים |
| מבנה גג | גובה ÷ קומות מעל 3.5 — יש קומה חלקית; לא בונים על הגובה |
| אין `units_count` | Snapland לרוב בלי מספר יחידות לבניין. משלימים מנסח, מיחידות דיוור או מספירת תיבות דואר; בלי זה אין גודל ממוצע |
| היתר אינו מצב קיים | סגירות מרפסות, הרחבות ופיצולי דירות אינם בהיתר. תמיד דגל |
| מבנה שנבנה אחרי ההיתר | `authorized_floors` ריק → לוקחים מ-`buildings` ומתייגים "בנוי" |
| "נטו" בהערכות | ב-הערכות ובתחשיבי מזמין "נטו" הוא לרוב ברוטו בפועל (נטו ≈ ברוטו × 0.9) |
| שטח טאבו גבוה מהחישוב | סימן לשטח שנספר פעמיים, למרפסות בפוליגון או לפיצול יחידות |
| `total_floor_area_sqm` | לא תמיד מלא ולא תמיד מבחין ברוטו משטח עיקרי. סותר את החישוב → `סותר`, שני הערכים |
| כמה מבנים על חלקה | כל מבנה נספר בנפרד; כניסות נספרות לכל מבנה, לא לחלקה |
