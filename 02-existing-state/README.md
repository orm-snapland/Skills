# 2 · בדיקת מצב קיים
מה בנוי על החלקה היום, בשתי רמות דיוק.

- `existing-state-check` – מצב קיים מנתוני Snapland: מבנים, יח"ד, ברוטו, גרעין, גודל ממוצע ומקדם קיים, מול הטאבו ומול ההיתר. ●●○○. פורק מתוך go-no-go-v3 (צעד 6 של שלב 1).
- `permit-measurement` – מדידת היתר: פוליגונים מדויקים מתשריט. ●●●○. מזין את `existing-state-check` דרך `measurement`.
- מתוכנן: קריאת גרמושקה / טאבו, קריאת צו בית משותף
