# קריאת תשריטי היתר — מוסכמות ומלכודות

## מוסכמות גרפיות (היתרים ישנים, שנות 50–80)
| סימון | משמעות |
|---|---|
| קיר אדום / ורוד | קיר מבוקש (בנייה חדשה בהיתר) — זה מה שמודדים |
| ריבוע כחול / קיר כחול | עמוד / בטון (בחתך: תקרות כחולות) |
| קווי עיפרון דקים | קווי מידה, ריהוט, מדרגות, קווי עזר |
| ריבוע עם X | חלל: פיר (מעלית/אשפה/אוורור), שקע פתוח, "חצר אוורור" — לא שטח רצפה |
| מקווקו / קווים קצרים אדומים | מעקה, רשת, קיר תריס (למשל ליד פחי אשפה) |
| "חדר ½" / "½ חדר" | חצי חדר — נספר לחישוב חדרים (2.5, 3.5, 4.5) |
| מספר עם מעריך (20⁶²) | שטח חדר במ"ר (20.62), בדרך כלל נטו |
| `4"` ליד חלל | צינור/מרזב 4 אינץ' — רמז לשקע שירות/ניקוז |
| "קומות א-ד" | קומה טיפוסית שחוזרת בקומות א' עד ד' |

כל המידות בס"מ. שרשרת חיצונית אחת = מידה כוללת; שרשרת שנייה = פירוק לפי בליטות/שקעים.

## טבלאות שטחים של אדריכל
- **שיטת "מלבן פחות שקעים":** מלבן חוסם (למשל 1837×1860), שקעים ממוספרים 1..n עם רוחב×עומק, והשארית = שטח קומה. השרטוט הקטן שליד הטבלה ממספר את השקעים — זו המפה הישירה למעטפת.
- **מרפסות:** רשימה נפרדת, לעיתים עם אחוז משטח הקומה (בשנות ה-60 תקרה ~30%).
- **"השטח הפנימי של הדירה הגדולה":** סכום שטחי חדרים נטו — לעיתים כולל מרפסות. לבדוק לפני השוואה.
- **מקלט:** ברוטו (כולל קירות עבים) + חישוב דרישה ("4 דירות בנות X חד' × ...").
- **קומת קרקע:** "שטח סגור" (לובי, מדרגות, אשפה, חשמל) מול "שטח פתוח/מפולש".
- **גג:** חדר כביסה / יציאה לגג / חדר מכונות.

## מלכודות שכבר קרו
1. **טעויות חשבון של האדריכל.** סנהדרין 7: 594×632 נרשם 37.72 (נכון: 37.54); 293×189 נרשם 5.49 (נכון: 5.54). תמיד לחשב מחדש כל שורה.
2. **בניין מפוצל-מפלסים.** החתך מראה מפלסים שונים בשני צדדים (סנהדרין: ‎+8.55 מול ‎+7.85). שני הפודסטים של חדר המדרגות הם "קומות כניסה" — אחד לכל דירה. אחרת נראה שדירה אחת בלי כניסה.
3. **פיר X בפודסט** שבחתך יורד לבור במרתף ועולה מעל הגג = פיר מעלית מתוכנן (לא תמיד בוצע). משותף.
4. **קיר חוץ משופע** (קו מגרש לא אורתוגונלי) — האדריכל מתעלם (מלבן). לשמור על המלבן "לפי היתר" ולרשום את הפער בדגלים.
5. **פיקסלים מטעים.** סטייה של עד 20–30 ס"מ בין מיקום בסריקה למידה הכתובה, ולא אחידה לאורך הגיליון. כיול למקוטעין + עדיפות למידה כתובה.
6. **מרפסת שבולטת מעבר למלבן החוסם.** המלבן של האדריכל הוא לשטח הבנוי; מרפסות (למשל עומק 220 = 99 בתוך המלבן + 121 מחוץ) יכולות לחרוג ממנו.
7. **פתח בלי דלת מצוירת** בין פודסט לדירה — בהיתרים ישנים דלתות לא תמיד מסומנות. להסיק כניסה מהגיון התנועה ולדגל.

## הגדרות שטח (לטבלה ולדגלים)
- **ברוטו לפי היתר:** עד הפאה החיצונית של קירות חוץ, עד קו האמצע של קיר משותף (לדירה אחרת / למשותף). בלי מרפסות פתוחות.
- **תקנות המכר (דירות) 2008:** כולל קירות חוץ מלאים, ומחצית קיר משותף לרכוש משותף; קירות בין דירות — לפי קו אמצע; מרפסות בנפרד.
- **נטו רצפה:** פנים קירות. ≈ ברוטו × 0.88–0.92 בבנייה של שנות ה-60.
- שטח רשום בטאבו קרוב לרוב לנטו + חלק יחסי; לא להשוות ישירות לברוטו.

## השוואה להערכות ולמודלים
- פוליגון בניין ממערכת (קו גג / תצ"א) ≈ מעטפת + מרפסות (סנהדרין: 251 מול 191.43+57.36=248.79).
- מודל לקוח של "שטח לדירה" כולל לעיתים חלק מהמדרגות — לבדוק אם סכום הדירות שווה למעטפת + מרפסות.
- מספר יחידות היום > מספר היחידות בהיתר ⇒ פיצול. לבדוק בטאבו ובהיתרים מאוחרים — משנה את התמורות בהתחדשות עירונית.
