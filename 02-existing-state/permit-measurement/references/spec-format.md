# פורמט spec.json

קואורדינטות בס"מ, ראשית בפינה הדרום-מערבית של מעטפת הקומה, X מזרחה, Y צפונה (אם הצפון לא למעלה בתשריט — מסובבים כך ש-Y = צפון ומציינים ב-`origin_note`). פוליגון = רשימת קודקודים בלי סגירה, נגד כיוון השעון או עם כיוון השעון (לא משנה), בלי חיתוך עצמי.

```jsonc
{
  "meta": {
    "address": "סנהדרין 7, תל אביב",          // כותרת
    "slug": "סנהדרין-7",                      // שם קובץ
    "subtitle": "קומה טיפוסית (א׳–ד׳) · 2 דירות לקומה",
    "source": "תשריט היתר, ועדה מקומית ת\"א-יפו",
    "permit_date": "22.12.1966",
    "method": "ברוטו לפי היתר",
    "typical_floors": 4, "floors_label": "א׳–ד׳",
    "origin_note": "(אופציונלי) תיאור הראשית אם שונה",
    "headline_flag": "HTML קצר לתיבת הדגל האדומה"
  },
  "envelope": [[x,y], ...],                    // שטח קומה בנוי (בלי מרפסות)
  "units":   [{"id":"N","name":"דירה צפונית","rooms":"2.5","poly":[...],"note":"...","label_at":[x,y]}],
  "common":  [{"id":"ST","name":"חדר מדרגות + פיר","short":"מדרגות + פיר","poly":[...],"note":"..."}],
  "balconies":[{"id":"B1","name":"מרפסת צפונית","unit":"N","dims":"850×220","poly":[...]}],
  "voids":   [{"id":"V1","name":"שקע X – לא נכלל","poly":[...]}],
  "other_common": [                            // מחוץ לקומה הטיפוסית
    {"id":"G","name":"קומת קרקע – שטח סגור","poly":[...],"floors":1,"note":"..."},
    {"id":"M","name":"מקלט","area":32.82,"formula":"=6.94*3.80+3.13*2.06","floors":1,"note":"..."}
  ],
  "checks": [ {"label":"שטח קומה","ours":"envelope","architect":191.26,"note":"..."} ],
  "flags":  ["<b>כותרת.</b> טקסט", ...],
  "calibration": {"scan":"/home/claude/scan/scan-000.png","x":[[cm,px],...],"y":[[cm,px],...]}
}
```

- `units` + `common` חייבים לכסות בדיוק את `envelope` (build.py --check בודק). אם יש כמה טיפוסי קומות — spec נפרד לכל טיפוס.
- `ours` ב-checks: `envelope`, `balconies`, `units`, `U:<id>`, `C:<id>`, `B:<id>`, `O:<id>`, או מספר.
- `label_at` אופציונלי — כשהנקודה האוטומטית נופלת במקום לא קריא (צוואר צר).
- `calibration` אופציונלי — בלעדיו אין עמוד אימות. נקודות בפיקסלים של התמונה המלאה (לא אריח).
- `formula` ב-other_common נכתב לאקסל כנוסחה חיה; `area` משמש ל-PDF.
